# Cinematic Birthday Surprise Project

A beautiful, cinematic web-based birthday surprise project featuring animations, music, and a memory gallery.

## Features
- ✨ Cinematic Hero Section
- 💌 Interactive Message Slider
- 💡 Celebration Stage (Interactive Lights, Music, and Balloons)
- 🎭 Dramatic Curtain Reveal
- 📸 Memory Gallery with Hover Effects
- ❤️ Floating Heart Particles

## How to Customize
You can easily customize this project by editing the `index.html` file:

1. **Change the Name**: Look for the `CONFIG` object in the `<script>` section at the bottom and change `recipientName`.
2. **Change the Music**: Update the `audioUrl` in the `CONFIG` object with your preferred MP3 link.
3. **Change Images**: Replace the Unsplash URLs in the Gallery Section (`gallery-grid`) with your own image URLs.
4. **Change Messages**: Edit the text inside the various `<section>` tags to personalize the messages.

## How to Run
Simply open `index.html` in any modern web browser, or serve it using a local server:
```bash
# Example using Python
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
